# 월간 가계부

월별 저축·투자 목표/실제납입, 고정지출, 카드값, 실현손익을 관리하는 개인 가계부입니다. 파일 하나(`index.html`)로 동작하고 서버가 필요 없습니다.

## 기능

- **가계부**: 월 수입, 저축·투자 / 고정지출 / 카드값의 목표·실제·차이, 실현손익(단기·중장기), 메모
- **달력**: 날짜별 소비 기록. 결제수단을 고르면 카드값 '실제' 칸에 자동으로 더해짐
- **구독**: 구독 서비스 요금·결제일·상태 관리, 월·연간 합계
- **할 일**: 매달 반복 / 한 번만 체크리스트
- **연간**: 12개월 요약표, 구글 시트용 복사 버튼
- **더보기**: 돈 관리 원칙과 시기별 흐름

## 데이터 저장

입력한 내용은 **사용하는 브라우저(localStorage)에만** 저장됩니다.

- 다른 기기나 다른 브라우저에서는 보이지 않습니다.
- 브라우저 데이터를 지우면 함께 지워집니다.
- 중요한 내용은 연간 탭의 "구글 시트로 보내기"로 주기적으로 백업하세요.

## GitHub Pages로 배포하기

1. 이 폴더의 파일을 새 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

## 휴대폰 홈 화면에 앱처럼 추가하기

- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: ⋮ 메뉴 → "홈 화면에 추가"

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 보입니다.
