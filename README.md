# 월간 가계부 (앱)

휴대폰 홈 화면에 설치해서 쓰는 개인 가계부 앱입니다. 누구나 받아서 자기 항목으로 바꿔 쓸 수 있고, 설치 후에는 인터넷이 없어도 열립니다.

## 기능

- **가계부**: 월 수입, 저축·투자 / 고정지출 / 변동지출의 항목·금융사별 목표와 실제 금액, 실현손익, 메모, 예산 자동 이월
- **달력**: 날짜별 소비 기록. 결제수단을 고르면 변동지출 '실제' 칸에 자동 반영
- **구독**: 구독 서비스 요금·결제일·상태, 월·연간 합계
- **할 일**: 매달 반복 / 한 번만 체크리스트
- **연간**: 12개월 요약표, 구글 시트용 복사
- **더보기**: 테마 5종, 내 사주(생년월일시 입력 → 사주 여덟 글자·오행·대운 계산)와 사주에 맞춘 돈 관리 원칙, 백업·복원
- **편집**: 섹션 이름, 항목·금융사, 실현손익 이름, 달력 분류, 할 일 문구를 모두 바꿀 수 있고 새 섹션도 추가 가능

## 사주 계산에 대해

외부 서비스에 접속하지 않고 앱 안에서 만세력 공식(태양 황경으로 절기 계산)으로 계산합니다. 생년월일은 기기 밖으로 나가지 않습니다. 양력·한국 표준시 기준이며, 절기 경계 시각에 태어났거나 서머타임 시기(1948~1960, 1987~1988)라면 결과가 다를 수 있습니다. 재미와 참고용입니다.

## 1. GitHub에 올리기

이 폴더 안의 파일을 **폴더 구조 그대로** 저장소 맨 위에 올립니다.

```
index.html
manifest.webmanifest
sw.js
icons/
  icon-192.png
  icon-512.png
  maskable-512.png
  apple-touch-icon.png
```

`icons` 폴더가 빠지면 앱 아이콘이 나오지 않아요.

## 2. GitHub Pages 켜기

1. 저장소 **Settings → Pages**로 갑니다.
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.

## 3. 휴대폰에 앱으로 설치

위 주소를 휴대폰에서 연 뒤:

- **아이폰**: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

홈 화면의 "가계부" 아이콘으로 열면 주소창 없는 앱 화면으로 열립니다.

## 데이터 저장과 백업

- 기록은 **그 기기 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 휴대폰과 PC는 서로 공유되지 않습니다.
- 앱을 지우거나 브라우저 데이터를 삭제하면 기록도 지워집니다.
- **더보기 → 백업·복원**에서 한 달에 한 번쯤 백업 파일을 저장해 두세요. 새 기기에서는 같은 메뉴에서 불러오면 됩니다.

## 파일을 고친 뒤

`sw.js`의 `VERSION` 값을 바꿔서(`ledger-v1` → `ledger-v2`) 함께 올려야 설치된 앱에 새 버전이 반영됩니다.
