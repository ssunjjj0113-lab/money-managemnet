# 월간 가계부 (앱)

휴대폰 홈 화면에 설치해서 쓰는 개인 가계부 앱입니다. 설치 후에는 인터넷이 없어도 열립니다.

## 기능

- **가계부**: 월 수입, 저축·투자 / 고정지출 / 카드값의 목표·실제·차이, 실현손익(단기·중장기), 메모, 항목 추가·편집
- **달력**: 날짜별 소비 기록. 결제수단을 고르면 카드값 '실제' 칸에 자동 반영
- **구독**: 구독 서비스 요금·결제일·상태, 월·연간 합계
- **할 일**: 매달 반복 / 한 번만 체크리스트
- **연간**: 12개월 요약표, 구글 시트용 복사
- **더보기**: 돈 관리 원칙, 시기별 흐름, 백업·복원

## 1. GitHub에 올리기

이 폴더 안의 파일을 **폴더 구조 그대로** 저장소 맨 위에 올립니다.

```
index.html
manifest.webmanifest
sw.js
icons/
  icon-192.png
  icon-512.png
  maskable-512.png
  apple-touch-icon.png
```

`icons` 폴더가 빠지면 앱 아이콘이 나오지 않아요.

## 2. GitHub Pages 켜기

1. 저장소 **Settings → Pages**로 갑니다.
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.

## 3. 휴대폰에 앱으로 설치

위 주소를 휴대폰에서 연 뒤:

- **아이폰**: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

홈 화면의 "가계부" 아이콘으로 열면 주소창 없는 앱 화면으로 열립니다.

## 데이터 저장과 백업

- 기록은 **그 기기 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 휴대폰과 PC는 서로 공유되지 않습니다.
- 앱을 지우거나 브라우저 데이터를 삭제하면 기록도 지워집니다.
- **더보기 → 백업·복원**에서 한 달에 한 번쯤 백업 파일을 저장해 두세요. 새 기기에서는 같은 메뉴에서 불러오면 됩니다.

## 파일을 고친 뒤

`sw.js`의 `VERSION` 값을 바꿔서(`ledger-v1` → `ledger-v2`) 함께 올려야 설치된 앱에 새 버전이 반영됩니다.
